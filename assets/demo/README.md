# Demo image

`sample_hc18.png` is a single fetal-head ultrasound frame from the **HC18 Grand Challenge** dataset (van den Heuvel et al., *PLOS ONE* 13(8):e0200412, 2018), redistributed under **CC BY 4.0**. Source: https://doi.org/10.5281/zenodo.1322001

It is included only as a demo input for the Part A inference quickstart. No other dataset images, masks, or ground-truth labels are redistributed in this repository.
